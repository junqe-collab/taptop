# 첫 전투 구현 범위

이 문서는 첫 전투 버전의 기록이다. 현재 구현 계약은 [3층 원정](dungeon_run.md)이다.

결정 사항 원문: https://chatgpt.com/space/page_0d3fd9ab32c4819181380babaf75e5a6

## 구현할 흐름

원정 시작 → 탐색 이벤트에서 장비 선택 → 첫 전투 → 승리 또는 패배 → 승리 시 스킬 즉시 습득 또는 포기 → 다시 시작.

Android 세로 화면과 터치 입력을 기준으로 하며, Godot 편집기에서도 실행한다. 그래픽은 같은 에셋 팩의 2D 정지 이미지와 카드로 구성한다.

## 적용할 확정 규칙

- 스탯은 체력, 마력, 물공, 물방, 마공, 마방, 속도다.
- 아군과 적은 속도 + 랜덤 가중치에 따라 행동한다. 속도는 행동 횟수를 늘리지 않는다.
- 라운드 시작 시 순서와 적 행동을 공개하고 카드를 선택한다. 선택을 바꿔도 순서를 다시 추첨하지 않는다.
- 우선도가 같으면 속도로 비교하고, 속도까지 같으면 추첨한다. 속도 변경은 다음 라운드에 반영한다.
- 파티가 습득한 스킬로 공용 덱을 구성한다. 라운드마다 카드 하나를 선택하고 나머지 캐릭터는 기본 행동을 한다.
- 마력은 실제 시전에 소비한다. 시전 전에 쓰러지면 취소하고 마력을 소비하지 않는다.
- 자동 대상 스킬은 실행 시 생존 대상을 고른다. 일반 치유로 부활하지 않는다.
- 방어막은 생성 즉시 적용하고 대상의 다음 행동 시작 시 남은 양이 소멸한다.
- 스킬은 몬스터 드랍 또는 상점에서 얻고 그 자리에서 캐릭터에게 습득시킨다. 보관할 수 없다.
- 스킬 수는 캐릭터 레벨 이하이고 1차 최대 레벨과 스킬 수는 4다.
- 습득한 스킬은 기본 능력치를 올리며, 해제는 특수 이벤트에서만 가능하다.
- 장비는 이벤트 또는 상점에서 얻는다. 몬스터는 장비를 드랍하지 않는다.

## 이번 프로토타입의 임시 설정

- 파티 3명, 적 2명, 첫 전투 1개를 제공한다.
- 시작 캐릭터는 레벨 1이며 시작 스킬 1개를 갖는다. 모든 보유 카드를 보여준다. 드로우·버리기 더미는 이번 범위에 포함하지 않는다.
- 탐색 장비는 레온에게 장착하는 청동 검(물공 +3) 또는 철제 방패(물방 +2) 중 하나다.
- 순서의 랜덤값은 정수 -2~+2다.
- 피해량은 공격 위력에서 해당 방어력을 뺀 값이며 최소 1이다.
- 행동은 캐릭터당 라운드 1회다. 기본 공격은 마력을 소비하지 않는다.
- 자동 공격은 생존한 적 중 앞에 있는 대상을 공격한다. 치유는 생존 아군 중 현재 체력 비율이 가장 낮은 대상을 고른다.
- 같은 캐릭터의 동일 스킬 중복 습득은 막는다. 다른 캐릭터의 습득에는 영향을 주지 않는다.
- 첫 전투 승리 시 전원 경험치 10을 얻어 레벨 2가 된다. 체력과 마력을 자동 회복하지 않는다.
- 승리 드랍은 잔불 화살 1개다. 습득 시 마공 +2, 최대 마력 +2이며 현재 마력은 회복하지 않는다.
- 다시 시작하면 파티, 레벨, 스킬, 장비, 전투 상태를 초기화한다.

수치와 임시 설정은 밸런스 검토 대상이며, 게임 전체의 확정 규칙으로 취급하지 않는다.

## 이후 범위

첫 전투 이후 층 진행, 휴식, 상점, 특수 스킬 해제 이벤트, 저장·불러오기는 이번 실행 구간에 포함하지 않는다. 휴식은 자원을 사용한 회복과 휴식 이벤트로 구성하며 스킬 훈련은 제외한다.
