# 3층 원정 구현 계약

## 확정 규칙

- Android 세로 화면, 2D 정지 캐릭터와 카드, 탐색 → 전투 → 휴식 사이클.
- 체력/마력/물공/물방/마공/마방/속도만 사용한다.
- 캐릭터는 라운드당 한 번 행동한다. 순서는 속도 + 무작위 가중치다.
- 캐릭터 레벨당 스킬 슬롯 1개, 최대 레벨 4와 슬롯 4개.
- 스킬은 몬스터 드랍 또는 상점에서만 획득하고 즉시 캐릭터에게 습득시킨다. 지나간 습득 기회는 보관되지 않는다.
- 스킬 습득은 기본 능력치를 올린다. 해제는 특수 이벤트에서만 가능하며 해당 스킬의 능력치 보너스도 제거한다.
- 장비는 탐색 이벤트 또는 상점에서만 획득한다. 몬스터는 장비를 드랍하지 않는다.
- 휴식은 자원 소모 회복과 별도의 휴식 이벤트로 구성한다. 스킬 훈련은 제공하지 않는다.

## 이번 구현의 수치와 선택 구조

아래 수치와 콘텐츠 구성은 이번 버전의 밸런스 설정이다.

- 3개 층 × 층당 전투 2회. 3층의 두 번째 전투는 최종 보스다. 총 6회 승리하면 원정을 완료한다.
- 전투마다 파티 전원 경험치 10. 누적 경험치 10/30/50에서 레벨 2/3/4. 최종 보스 전에 레벨 4가 된다. 레벨 상승은 현재 체력·마력을 회복하지 않는다.
- 레벨당 최대 체력 +5, 최대 마력 +2, 물공 +1, 마공 +1. 스킬·장비·휴식 이벤트의 능력치는 별도로 합산한다.
- 레온과 동료 후보 4명 중 2명으로 파티를 구성한다. 원정 중 동료 교체는 없다. 전투 밖에서 전열을 변경할 수 있다.
- 탐색마다 두 경로 중 하나를 선택한다. 경로는 이벤트와 적 구성을 미리 보여준다. 위험 경로는 적이 강화되고 골드 보상이 증가한다.
- 보급함은 무작위 장비 중 하나를 한 명에게 지급한다. 무기/방어구 각 1슬롯이며 같은 부위는 교체하고 이전 장비는 버린다.
- 상점은 스킬 3개, 장비 2개, 식량 1개를 제공한다. 스킬과 장비는 수령 캐릭터를 정해 구매한다. 습득 불가/골드 부족이면 결제하지 않는다. 구매한 상품은 소진된다.
- 망각의 제단은 원정 중 스킬을 해제할 수 있는 특수 이벤트다. 방문당 한 번만 사용할 수 있다.
- 전투 승리 시 스킬 2개를 차례로 제시한다. 각각 즉시 습득하거나 포기한다. 중복 습득 금지는 같은 캐릭터에만 적용한다.
- 공용 덱은 파티의 습득 스킬을 캐릭터별 카드로 구성한다. 라운드마다 최대 5장. 카드 1장을 선택하고 나머지 캐릭터는 기본 공격한다. 기본 공격은 손패나 마력이 없어도 선택할 수 있다.
- 라운드 종료 시 손패 전체를 버린다. 다음 손패는 남은 덱에서 먼저 뽑고, 부족하면 버린 카드를 섞는다. 같은 손패 안에서 동일 카드는 중복되지 않는다. 쓰러진 캐릭터의 카드는 뽑지 않는다.
- 순서 가중치는 -2~+2. 동점은 속도, 그 뒤 추첨으로 결정한다. 카드 선택으로 순서나 손패를 다시 뽑지 않는다.
- 물리/마법 단일 공격, 전체 공격, 방어 무시 공격, 흡혈, 단일/전체 치유, 개인/파티 방어막을 제공한다. 습득 능력치로 특화 방향을 선택한다.
- 휴식마다 식량 1개로 파티 최대 체력의 55%, 최대 마력의 60%를 회복한다. 쓰러진 동료도 이때 회복한다. 전멸하면 휴식에 도달하지 못하고 원정이 끝난다. 각 휴식의 회복은 한 번만 가능하다.
- 휴식 이벤트는 무작위 능력치 변화 하나를 제시하며 한 명에게 적용하거나 지나갈 수 있다. 식량 회복과 독립적이며 반복 적용할 수 없다.
- 체력·마력과 골드·식량은 전투 사이에 유지한다. 기본 지급은 골드 40, 식량 3이다.
- 원정 시드를 표시하고 같은 시드로 재도전할 수 있다. 탐색/보상 난수와 전투 난수는 분리한다. 화면 갱신이나 선택 취소로 보상이 바뀌지 않는다.
- 전멸 후 재시작은 성장, 장비, 스킬, 자원, 덱을 초기화한다. 출발 동료 선택은 유지한다.

## 화면과 전투 피드백

- 전투 화면은 전장, 행동 순서, 가로 손패, 실행 영역을 한 화면에 배치한다. 손패는 좌우로 넘긴다.
- 실제 행동 결과의 공격자와 대상 정보를 별도로 기록한다. 연출은 이 결과만 사용하며 전투 난수나 피해 계산에 영향을 주지 않는다.
- 물리 공격은 접근과 타격, 마법은 투사체, 치유와 방어막은 다른 색과 기호로 표시한다. 대상에게 피해·회복·흡수 수치와 체력 변화를 표시한다.
- 전투 중 화면 전체를 행동마다 재생성하지 않는다. 마지막 타격 연출을 마친 후 보상 또는 패배 화면으로 이동한다.
- 탐색은 층 진행 표시와 두 갈림길 카드, 상점은 상품 종류별 탭, 습득과 휴식 이벤트는 캐릭터 카드 선택으로 처리한다.

## 0.4.0 모바일 원정 개선 계약

- 준비부터 결과까지 게임 루트는 스크롤하지 않는다. 상세 정보·편성·유물·제단은 별도 창 내부에서만 세로 스크롤한다. 손패는 별도 트레이 안에서 가로로 넘긴다.
- 모바일 360×640, 390×844, 412×915 및 짧은 360×560 영역에서 주요 행동이 화면 안에 들어오는지 검사한다.
- 몬스터·캐릭터·스킬·장비·유물·전장 특성·적 행동 정의는 game_data.gd에서 관리한다. battle.gd는 순수 상태/규칙, 화면은 표시/입력만 담당한다.
- 준비 시 유물 6종 중 3종을 시드로 추첨하고 하나를 선택한다. 출발 후 변경할 수 없다.
- 두 경로는 서로 다른 전장 특성을 미리 보여준다. 물리/마법 강화는 양측에 적용하며 비용 감소·치유 강화도 수치로 표시한다. 화면 갱신으로 다시 뽑지 않는다.
- 적을 눌러 단일 공격 집중 대상을 선택한다. 기본 공격과 단일 공격 스킬에 적용하며 대상 사망 시 생존 적으로 변경한다. 전체 공격·아군 지원은 기존 규칙을 따른다.
- 전투당 손패 교체 1회. 행동 시작 전만 가능하며 선택 카드는 초기화되고 순서와 적 예고는 유지된다. 교체 가능한 덱이 없으면 비활성화한다.
- 전장 색·환경 입자·대상 테두리·타격 파편·유물 발동은 규칙 상태를 읽어 표시하고 난수를 소비하지 않는다.
- 완료 기준: 전 단계 화면 안 배치, 6전투 실제 입력 진행, 기존 규칙 회귀, 새 시스템과 시드 재현 검사를 통과한다. 재미는 선택 차이와 재도전 가능한 루프로 검토하며 실제 사용자 체감으로 단정하지 않는다.

## 구현 범위

저장·불러오기, 영구 성장, 실시간 이동, 4층 이상은 포함하지 않는다. 기존 첫 전투 문서는 이전 버전의 기록이며, 현재 실행 계약은 이 문서다.
